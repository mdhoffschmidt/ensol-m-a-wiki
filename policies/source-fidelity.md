# Fidelite aux sources

## Regles

- Tout chiffre, date ou citation directe est localise dans le fichier raw avant d'etre ecrit.
- Reproduire les chiffres tels que la source les donne : si la source dit `42K`, ecrire `42K`, pas `42 000`.
- Une valeur derivee affiche ses composants pour que chacun reste retrouvable.
- Une valeur introuvable est abandonnee ou marquee `[nc]`.
- Quand une information recente peut avoir change, verifier la source avant d'ecrire.

## Fiabilite des chiffres

- `haute` : source officielle, comptes publies, greffe, INSEE, Banque de France, documentation fournisseur verifiable.
- `estime` : calcul, interpolation, extrapolation, benchmark ou hypothese construite.
- `declaratif` : auto-declare, presse, commercial, site d'entreprise, entretien non audite.
- `nc` : non chiffre ou non confirme.
